# Where the docs come from

The files in `data/raw/` are a snapshot of the English FastAPI documentation.

- Project: https://github.com/fastapi/fastapi
- Folder copied: `docs/en/docs`
- Commit: `45cb2252c737906f37544f5ba6bee0295fb81468` (2026-10-31)
- Author and copyright holder: Sebastian Ramirez
- License: MIT. The full text is in [LICENSE-fastapi](LICENSE-fastapi).

These files are not part of this project's own code. They belong to the FastAPI authors and are used here only as sample text to search.

## What was left out

Pages that would add noise to search were not copied: the API reference stubs, release notes, contributor and management pages, the newsletter, and the people page. Images and other non-text files were also skipped.

The snapshot is pinned to one commit so that later evaluation numbers can be reproduced.
